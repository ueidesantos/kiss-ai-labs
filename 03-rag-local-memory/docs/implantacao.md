# Implantação de serviços

Antes de uma implantação, confirme que a revisão de código terminou, as verificações aplicáveis passaram e existe um plano de reversão. Implantações de alto impacto devem ser acompanhadas por uma pessoa responsável.

Após a implantação, verifique os indicadores de saúde e registre o resultado. Se houver regressão, interrompa a expansão e reverta para a versão estável anterior.
